# Long An Solutions — marketing site

Static HTML site for [longansolutions.com](https://longansolutions.com/),
deployed via GitHub Pages from `master`. No build step — edit the `.html`
files directly and push.

- `index.html` — homepage
- `dung-thu.html` — ad-only landing page (intentionally not linked in nav or sitemap)
- `knowledge.html` + `knowledge/*.html` — the knowledge base / article section
- `privacy.html`, `terms.html` — legal pages
- `assets/knowledge.css` — shared stylesheet for the hub and every article
- `sitemap.xml`, `robots.txt` — for search discovery

**Publishing a new knowledge article?** Follow [`PUBLISHING.md`](PUBLISHING.md)
— it's a step-by-step template and checklist, not just notes.
